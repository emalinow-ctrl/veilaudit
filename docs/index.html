Find every face your censoring pipeline missed.

VeilAudit is an offline pipeline that audits folders of video for improperly censored faces — before a failed redaction becomes someone's problem. Detection, blur forensics, per-person tracking and a human review loop. All local, all the time.

01 — DETECT

Every face, every sampled frame

InsightFace SCRFD (buffalo_l) on a downscaled frame for speed; blur is always measured on the native-resolution crop so compression can't hide the truth.

02 — FORENSICS

Metrics that survive real footage

Laplacian variance, FFT high-frequency ratio, edge density, flat-block analysis for pixelation, solid-mask checks for black bars. Motion blur vs censor blur, told apart.

03 — TRACK

Per-person verdicts, not per-frame

A stable ID per person with a vote history. One lucky sharp frame can't condemn you, and a blurred neighbour can't cover for you.

04 — HUMANS

A review queue, not a guess

Borderline calls go to a local review UI. Labels feed back through learn.py: thresholds retune, an optional MobileNetV3 tiebreaker improves. Label → retrain → redeploy.

05 — EVIDENCE

Reports a human can act on

Flagged frames with red boxes and track IDs, report.csv/report.json with metric values, per-person summaries. SQLite checkpoints: crash, Ctrl-C, resume.

06 — OFFLINE

Your footage never leaves the machine

No cloud APIs, no telemetry, no accounts. One-time model download, then pull the network cable. Synthetic fixtures only in the repo — user video is gitignored.

Run it

# audit a folder of video (first run downloads the model pack once)
python main.py --input-dir /data/videos --output-dir /data/audit_out --workers 4

# score against ground truth / your own labels
python tests/evaluate.py --gt gt/ --out audit_out

# calibrate thresholds to YOUR footage before trusting defaults
python calibrate.py --video /data/videos/sample.mp4 --out calib_out
